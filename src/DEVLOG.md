Журнал разработки проекта Vanilla Space

Документация ключевых архитектурных изменений, исправления критических ошибок компиляции и интеграции сторонних библиотек.



 Запись 1  22.07.2026

 1. Архитектурные изменения и паттерны
Переход на Feature-Sliced Design (FSD): Структура проекта реорганизована в соответствии со спецификацией FSD. Инициализированы слои `app`, `pages`, `widgets`, `features`, `entities`, `shared`. Слой `processes` исключен.
Изоляция компонентов: Компонент `Header` со сквозной бизнес-логикой перенесен в слой `widgets`. Логика маршрутизации инкапсулирована в `AppRoutes.tsx` на уровне `app`.
Паттерн Public API: Для модулей (`pages/catalog`, `widgets/header`) созданы точки экспорта `index.ts`. Прямой импорт внутренних файлов модулей запрещен.
Настройка Absolute Aliases: Сконфигурированы абсолютные пути с префиксом `@/` для оптимизации структуры импортов.

 2. Разбор ошибок сборки и решений
Конфигурация TypeScript (tsconfig.app.json):
Проблема: Ошибка компиляции из-за устаревшего параметра `"baseUrl": "."` в окружении TypeScript 7.0+.
Решение: Удален параметр `baseUrl`, пути в блоке `paths` переведены на относительный префикс `./src/`. На стороне `vite.config.ts` подключено нативное разрешение путей Node.js через модуль `path` и метод `fileURLToPath`.
Сбой отображения стилей Tailwind CSS v4:
Проблема: Кастомные инлайновые размеры разметки (например, `pt-66.25`, `max-w-277.5`) игнорировались компилятором, что приводило к нарушению сетки макета.
Причина: Специфика Tailwind v4, требующая явной декларации нестандартных шагов spacing-сетки при отсутствии `tailwind.config.js`.
Решение: Сетка кастомных размеров и шрифт `Raleway` задекларированы напрямую в `src/index.css` через директиву `@theme`.

 3. Работа с данными
Имитация REST API: Реализован асинхронный запрос данных через хук `useEffect` к статическому файлу `/db.json`, размещенному в директории `public`. Настроена обработка структуры объекта данных с ключом `clothing`. Слайдер `Swiper.js` переведен со статических констант на динамический рендеринг массива.
